## Description

In HW 3, we continued to add features to the LOSC Event Tutorial notebook. Part one of the project required cleaning the notebook so that files could be saved in respective folders called data, audio, and figures. Ligotools was made to be an installable package, so tests were implemented for the utilities and readligo functions. After this, a Makefile was created to clean the different folders. Finally, the repository was built into a MyST that deployed the notebook and README files that included a binder link.
